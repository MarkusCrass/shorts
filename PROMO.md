# Промо своих треков через шортсы

Конвейер: **хайлайт из Dota 2 / CS2 + свой трек → готовый шортс для YouTube.**

Что он делает сам:

- 🎬 скачивает хайлайт (любой источник, который умеет yt-dlp);
- 🔇 **полностью убирает звук видео** — остаётся только ваш трек;
- 🎵 нормализует громкость трека (EBU R128, −14 LUFS — стандарт соцсетей);
- ✂️ берёт трек **с дропа** (указываете таймкод в `promo.json`);
- 🎞️ режет вертикаль 1080×1920, ставит фейды в начале и конце;
- 📝 генерирует название, описание со ссылками на трек и теги;
- 📦 пачкой: 1 трек × N фрагментов = N шортсов за один запуск.

---

## Быстрый старт

### 1. Положите треки

```
tracks/
  track01.mp3
  track02.mp3
```

Если в имени файла есть `140bpm` — скрипт сам подхватит BPM.

### 2. Заполните `promo.json`

```json
{
  "tracks": [
    {
      "id": "track01",
      "title": "ТВОЙ ТРЕК (название для описания)",
      "file": "tracks/track01.mp3",
      "bpm": 140,
      "drop_at": "00:32",
      "links": {"spotify": "https://open.spotify.com/track/..."}
    }
  ],
  "sources": [
    {
      "id": "dota_01",
      "game": "dota2",
      "url": "https://www.youtube.com/watch?v=odguY-kCJ8c",
      "segments": [
        {"name": "a", "start": "00:02:00", "hook": "Дроп"},
        {"name": "b", "start": "00:08:00"}
      ]
    }
  ]
}
```

`drop_at` — момент в треке, с которого начинать (обычно дроп/припев).
`start` — момент в видео. `hook` — текст на первых секундах (необязательно).

### 3. Запустите

```bash
python make_promo.py --list          # посмотреть план: сколько получится шортсов
python make_promo.py                 # собрать всё
python make_promo.py --per-track 3   # по 3 случайных фрагмента на каждый трек
python make_promo.py --track track01 # только один трек
```

Результат в `promo_out/`:

```
promo_out/
  track01__dota_01-a.mp4   ← видео с вашим треком
  track01__dota_01-a.jpg   ← превью
  track01__dota_01-a.txt   ← название, описание, теги — копируйте при загрузке
  uploads.json             ← всё сразу для автозагрузки
```

## Сколько шортсов получать

Просто добавьте больше фрагментов в `segments` — каждый станет отдельным шортсом.

| Задача | Как |
|---|---|
| 10 шортсов из одного трека | 10 фрагментов в `segments`, `per_track` не нужен |
| 20 шортсов из двух треков | 10 фрагментов × 2 трека |
| Разные треки на разные фрагменты | `--per-track 1` и несколько запусков с `--track` |
| Не повторяться | `--per-track 3` берёт случайные фрагменты |

## Настройки качества

| Параметр | Где | Значение |
|---|---|---|
| Длительность | `defaults.duration` | 15–30 сек (Shorts любит 15–25) |
| Вертикаль | `defaults.mode` | `crop` — центр 9:16, `blur` — фон |
| Хук | `segments[].hook` | 2–4 слова |
| Громкость | автоматически | −14 LUFS (как у Spotify/YouTube) |
| Плавность | `afade` 0.6 с | в начале и конце |

## Где брать хайлайты

- **Dota 2:** канал [BLAST SLAM Dota 2](https://www.youtube.com/@BLASTDota) — официальные хайлайты,
  короткие и динамичные. Также `Dota 2 Rapier`, `DLTV`.
- **CS2:** BLAST Premier, ESL, PGL — официальные хайлайты матчей.

Берите **официальные хайлайты** (они короткие, уже смонтированы) — из них шортсы
получаются лучше, чем из полных записей матчей.

## Автозагрузка в YouTube (когда понадобится)

Сейчас скрипт готовит файлы и тексты. Для автозагрузки нужен **YouTube Data API**:

1. В [Google Cloud Console](https://console.cloud.google.com/) создать проект.
2. Включить **YouTube Data API v3**.
3. Создать **OAuth-клиент** типа «Desktop» и скачать `client_secret.json`.
4. Один раз авторизоваться (браузер откроется сам) — токен сохранится.
5. Загружать из `uploads.json` — там уже готовые название/описание/теги.

Ограничение бесплатной квоты: ~6 загрузок в день (по 1600 единиц из 10 000).
Для 20 шортсов удобнее загружать в 2–3 дня или запросить увеличение квоты.
Скажите, когда будете готовы — допишу `upload_youtube.py`.

## Про авторские права — прочитайте

Это **важно** для промо-стратегии:

- ❌ Просто наложить свой трек на чужой хайлайт BLAST/ESL — риск Content ID
  на **видео** (права у организатора). Аккаунт может получить страйк.
- ✅ Безопаснее: короткие фрагменты (до 5–8 сек) с собственной обработкой
  (зум, фильтры, текст, ускорение) — это уже «трансформативное использование».
- ✅ Самый надёжный путь для промо: **свои записи игры** (свой счёт, свой
  геймплей) или стоковые/лицензированные клипы.
- ✅ Свой трек — ваш, но **не забудьте** указать его в описании и добавить
  ссылки; для монетизации трека используйте дистрибьютора (DistroKid и т.п.).

Проверяйте каждый ролик перед публикацией: Content ID срабатывает сразу
при загрузке, и вы увидите претензию в YouTube Studio.
